Helpdesk Management System

Project Overview

The Helpdesk Management System is a web-based application developed to simplify IT support management. The system allows users to report technical problems by creating support tickets, while technicians can view available tickets and assign tasks to themselves for resolution.

The main purpose of the project is to improve how technical issues are reported, monitored and managed.

Features

1. All Tickets
- View all reported support tickets.
- Display ticket ID and title.
- View ticket category and priority.
- Monitor ticket status (Open, In Progress, Resolved).
- See which technician is assigned to each ticket.

2. Log a Ticket
- Create and submit new support tickets.
- Report technical issues for assistance.
- Organise issues according to their category and priority.

3. Technician Queue
- View available and unassigned tickets.
- Identify issues according to their priority.
- Allow technicians to assign tickets to themselves.

4. Ticket Management
- Track the progress of reported issues.
- Identify assigned and unassigned tickets.
- Support the management of technical problems.

## Project Purpose

This project was developed as part of an academic group project at the Durban University of Technology (DUT). It provided an opportunity to apply software development concepts, work collaboratively as a team and develop a practical system that addresses a real-world IT support management problem.
